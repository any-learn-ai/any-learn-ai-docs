## 概要

任意のテーマを自由に指定できるAI個別指導システムの設計書群です。  
AIが学習目標の設定・理解度診断・個別最適化プログラムの生成・インタラクティブな指導をすべて担います。

## システム概要

```
ユーザーが学習テーマを指定
    ↓
AIが目標設定・期間・レベルをチャットで合意
    ↓
約20問のアセスメントで現在の理解度を診断
    ↓
診断レポート（強み・弱みの可視化）
    ↓
個別最適化された学習プログラムを自動生成
    ↓
学習マイクロサイクルで繰り返し学習
 ├─ 先生アバターが1概念を解説
 ├─ よくある質問3問をサジェスト（いつでも自由質問可）
 └─ 確認問題 → 正解で次へ / 不正解で再解説
    ↓
ゲームライクなUIで進捗・XP・レベルを管理
```

## 技術スタック概要

### フロントエンド
- Next.js 15 / React 19 / TypeScript
- Tailwind CSS + CSS Modules
- Framer Motion（アニメーション）
- Lottie Web（アバターアニメーション）
- Howler.js（サウンド）
- GSAP（演出シーケンス）

### バックエンド（AWS）
- API Gateway + AWS Lambda (Node.js 22)
- Amazon DynamoDB
- Amazon S3 / CloudFront
- Amazon Cognito（認証）
- Amazon Polly（テキスト読み上げ）
- Amazon Transcribe（音声認識）

### AI
- **Anthropic Claude API**（直接利用・AWS Bedrock不使用）
  - Claude Sonnet 4.8：学習プログラム生成・診断分析・アセスメント問題生成
  - Claude Haiku 4.5：リアルタイム会話・回答評価・Q&A・脱線検知

## ランディングページ

`index.html` は以下の特徴を持つ単一HTMLファイルのランディングページです：

- **KNOWLEDGE QUEST** ゲームテーマ（v1.3 ゲームUI設計準拠）
- ダークファンタジー × モダンモバイルゲーム の視覚デザイン
- Glassmorphismパネル + 紫/ゴールドカラーシステム
- Canvas 2D による流れ星・星空背景アニメーション
- AIメンターアバターの疑似UIモックアップ（実際の画面イメージ）
- XPバー・コンボカウンター・ストリーク・アチーブメントのプレビュー
- テーマピルの自動横スクロール
- IntersectionObserver による fade-in-up スクロールアニメーション
- 外部依存ゼロ（Google Fonts のみ）・単一ファイルで動作

### GitHub Pages での公開方法

リポジトリの Settings → Pages → Source を `main` ブランチ・ルートディレクトリに設定するだけで公開できます。
